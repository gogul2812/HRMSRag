# Project Phoenix — Overview

**Document type:** Project  
**Client:** Northstar Hospitals Group  
**Status:** Active  
**Owner:** Priya Nair (Delivery Manager)

## Summary

Project Phoenix is a digital patient intake and bed-management rollout for Northstar Hospitals. Demo Corp is delivering the integration layer, reporting dashboards, and staff training packs.

## Timeline

| Phase | Window | Outcome |
|---|---|---|
| Discovery | Jan–Feb 2026 | Requirements signed off |
| Build | Mar–May 2026 | Intake APIs + dashboards |
| Pilot | Jun 2026 | 2 hospitals live |
| Rollout | Jul–Sep 2026 | Remaining 6 hospitals |

## Important rules for this project

1. All PHI / patient data questions must stay on the **local / restricted** path — do not send patient identifiers to public cloud tools.
2. Change requests above **40 hours** need written approval from Dr. Helen Cho.
3. The pilot hospitals are **Riverside Central** and **Lakeview Specialty**.
